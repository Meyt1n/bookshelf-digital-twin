# 智慧书架 · 数字孪生驾驶舱

`bookshelf` 主项目（家庭智慧书架实体）的数字孪生前端。它把 2 层 × 4 格的实体书架 1:1 映射成一个实时 3D 孪生体：格口占用、升降取书机构、视觉识别（YOLO+OCR）、STM32 电机协议、紫外线消毒、塑封、环境遥测，全部在同一块驾驶舱大屏里可视、可控、可仿真。

## 视觉主题：极光晶体

深空蓝紫为底、靛蓝与冰青双主色的科技美学，重点是消除"大屏僵硬感"：

- 玻璃拟态面板 + 渐变描边（padding-box / border-box 双层渐变），面板顶部有周期游走的流光。
- 背景为缓慢漂移的极光渐变 + 点阵，顶栏底部是流动的三色细线。
- KPI、时钟等关键数字使用渐变文字（background-clip: text），字体为 Space Grotesk。
- 事件流为时间轴形态：主线渐隐、节点按级别着色、最新节点带扩散波纹。
- 导航为胶囊滑块，主操作按钮渐变实底，次操作幽灵按钮，全部带悬浮位移与光晕反馈。
- 3D 场景：蓝钢书架、霓虹分类色书本、靛/紫/青三色灯光、星尘缓旋。

## 真实书柜模型

3D 场景中的柜体来自实体书柜的 SolidWorks 模型（`智能书柜.STEP`，147 个零件），经 `cascadio` 转换为 GLB 并按功能拆分：

- `public/model/bookcase-body.glb`：柜体主体（立式铝材桁架、书槽区、运输带、放书架、显示屏），按部件类别染色。
- `bookcase-beam.glb`：悬梁臂横梁组（悬梁臂 ×2 + X 轴置物板 + 滑块），半透明磨砂金属材质，沿两根竖直导轨升降。
- `bookcase-head.glb`：柔性夹爪抓取头，左右夹爪拆分为独立 mesh（`gripper-left` / `gripper-right`），支持真实开合动画。

格口坐标系（`src/scene/layout.ts`）按真实模型标定：对 24 个 L 形隔板与 12 个履带电机做位置聚类，得到立式书柜「上下两层 × 每层 6 个立插书槽」的真实布局（槽宽 5.3cm、深 40cm，槽底履带送书）；数据库的 2 层 × 4 格映射为「上层/下层 × 中间 4 槽」。

龙门动画使用真实机械零件，三轴联动 + 机械质感：

- 横梁组沿竖直导轨升降（Y）、抓取头沿横梁横移（X）、柔性夹爪沿 Z 探入书槽夹书；
- 三轴均由临界欠阻尼弹簧跟踪引擎位姿，到位带轻微回弹；
- 夹爪探入时张开、触书夹合、携书微开，全程弹簧平滑；
- 探入时开启作业照明照亮目标槽；抓取头带能量场线框与识别光柱标识，移动时留下渐隐的轨迹光带与光点。

3D 视口右下角提供全景 / 正面 / 龙门 / 俯瞰四个相机预设与自动巡航。开发服务器固定在 `http://localhost:5188/`。

## 页面结构

顶栏提供四个页面的导航，以及链路指示灯、柜内温湿度速览、仿真/联机模式切换和时钟。

### 孪生总览

- 左栏：格口矩阵（与实体 2×4 布局一致）、选中格口详情（取书/指派存书）、在架图书清单、运行统计。
- 中央：Three.js 实时 3D 孪生场景（顶部发光铭牌、在架图书悬浮书名标签、hover 高亮与信息浮条）+ KPI 浮层 + 任务相位卡片 + 指令台。
- 右栏：环境遥测曲线、驱动电流、执行机构状态、STM32 I2C 寄存器镜像、实时事件流。

### 图书资产

全书目管理：搜索书名/作者、分类筛选、在架/离架状态筛选；每册图书卡片展示位置（层-格）、存入人、累计流转次数，支持一键取出/入库（入库自动走视觉识别流程并顺位分配格口）。

### 数据分析

运营大屏：今日存取/消毒/塑封/使用率/运行时长 KPI、近 7 天存取趋势（前 6 天为模拟历史+今天实时）、分类流转占比环图、成员活跃排行、格口使用热力图、24 小时时段活跃分布、温湿度历史曲线。

### 设备诊断

硬件孪生：数据链路拓扑大图（驾驶舱 ↔ Flask ↔ Pi 桥接 ↔ STM32，含流光动画与实测延迟）、8 个硬件单元健康卡（电机/推杆/摄像头/UV 灯管/热压辊/传感器/语音单元）、一键自检（对应 `pi_bridge/self_check.py` 流程仿真）、指令收发日志、I2C 协议镜像与码表说明。

## 孪生能力

- 任务状态机：取书/存书任务按「指令下发 → 控制器应答 → 机构移动 → 格口作业 → 机构归位」推进，与主项目 `services/stm32_protocol.py` 的寄存器协议（NEW_CMD_FLAG / CMD / FLOOR_ID / CELL_ID / ACK）一一对应，机械臂在 3D 场景中同步运动。
- 视觉入库仿真：拍照存书会复现「摄像头采集 → YOLO ROI → PaddleOCR → 图书匹配 → 顺位分配格口」的完整事件链。
- 语音行为仿真：开启「自主活动」后，家庭成员（数据源自主项目 users 表）会随机发起语音取书、现场存书。
- 模块仿真：紫外线消毒（3D 紫光扫描）、塑封书籍、急停（ACK=FAULT，机构返回待机位）。
- 遥测仿真：柜内温湿度随机游走曲线、电机电流随任务负载变化。

## 仿真 / 联机双模式

默认运行在**仿真模式**，内置书目与主项目 `data/bookshelf.db` 一致，无需后端即可完整演示。

点击顶栏「仿真运行」可尝试**联机**：

1. 先启动主项目后端：`cd ../bookshelf && python app.py`（默认 5000 端口）。
2. 开发模式下 Vite 已把 `/api` 代理到 `http://127.0.0.1:5000`（见 `vite.config.ts`）。
3. 联机后自动接入 `/api/voice_stream?since=now` SSE 事件流：实体端语音对话直通孪生事件流；实体存/取书事件实时驱动 3D 机械臂动画并即时刷新快照。轮询降级为 12s 对账通道（SSE 断开时自动回退 3s 快轮询，浏览器自动重连）。
4. 取书按钮走实体两段式流程（`/api/take` 准备 + `/api/motion/commit` 落库），孪生反向控制真实生效；链路面板显示 Flask 实测延迟。
5. 运行统计接入真实数据：联机时拉取实体 `borrow_logs`，周趋势、成员活跃度、格口热度全部换成真实存取记录（退出联机自动还原仿真统计）。
6. 温湿度接入真实遥测：联机时每 30s 拉取实体 `/api/climate`（传感器或天气耦合估算），曲线向真实值平滑收敛；退出联机恢复随机游走仿真。
7. 后端不可达时自动回退仿真模式；轮询失败会保留最近一次快照并告警。

联机身份沿用浏览器里 Flask 网页端的登录态（同主机 Cookie），先在 `http://127.0.0.1:5000` 登录一次即可。

也可以用环境变量指定后端地址（生产部署时）：`VITE_API_BASE=http://192.168.1.10:5000`。

## 3D 模型说明

柜体基于真实 STEP 模型（智能书柜.STEP）标定的尺寸程序化建模（`src/scene/layout.ts` 保存标定常量，
`Bookshelf.tsx` 的 `CabinetBody` 按常量拼装）。如果后续从 SolidWorks 导出 `bookcase-body.glb`
放到 `public/model/`，把 `CabinetBody` 换回 `useLoader(GLTFLoader, '/model/bookcase-body.glb')`
方案即可无缝替换（材质映射表 `BODY_MATERIALS` 已保留）。
